# 8482H POWER REF bench check — November 24, 2026

The **Agilent 8482H SN 3318A09219** indicated **1.0050 mW** on all three readings of the HP 437B’s nominal 50 MHz, 1.000 mW POWER REF output with **CAL FAC verified at 99.0%**. The indication was **0.50% above nominal**.

## Setup

- HP 437B **SN 3125U22346**, with firmware **2.0** observed over the XyphroLabs USBGpib V2 adapter.
- Owner-confirmed warm-up of at least 30 minutes. The intact 8482H RF input assembly connected directly to POWER REF, and the sensor cable connected to SENSOR.
- Mac with macOS 27.0.1 on arm64, Python 3.14.10, PyVISA 1.16.2, PyVISA-py 0.8.1, and PyUSB 1.3.1.
- Absolute watts, automatic range and filter, and REL, OFFSET, and duty-cycle correction off. The [serial-specific calibration chart](8482H-CALIBRATION-20261122.md#calibration-factors-as-printed) gives both the reference factor and the 50 MHz measurement factor as 99.0%.

## Observations

| Operation | Bench result |
| --- | --- |
| ZERO | POWER REF was off. The meter reported completion after **10.1 s** and immediately indicated **+3.0 µW** with the reference still off. |
| CAL | The meter reported completion after **16.8 s** with **REF CAL FACTOR 99.0%** and confirmed POWER REF returned to off. The completion polling window was 30 s. |
| Set CAL FAC | The meter accepted `KB99.0EN` and returned `CALFAC 099.0%` on readback before POWER REF was enabled. |
| POWER REF check | The meter confirmed POWER REF on. After 20 s of settling, three readings each indicated **1.0050 mW**. |
| Closure | The meter confirmed POWER REF off with no measurement or entry error, accepted the return to free-run and local control, and the USB session closed. The final closure evidence is from the protocol receipts. |

This check records the indication of the 437B/8482H pair on the same reference used for CAL. The independent POWER REF output measurement remains the **1.001 mW** result in the [meter’s laboratory record](CALIBRATION-REVIEW.md#reported-results). The bench result applies to the recorded setup.
