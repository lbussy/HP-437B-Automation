# Implement the conducted Pi 1 GPIO20 sweep

Implement the automatic frequency × drive runner for **one bench setup**. The Mac owns the HP 437B over USBGpib V2, and `wspr1.local` owns the Raspberry Pi 1 Model A+ BCM2835 native GPIO20 output. Use the 8482A SN **MY41094127** on HP 437B SN **3125U22346**. The operator reviews the exact 80-point plan and explicitly starts it. Use eight temporary loopback-only WsprryPi instances, one per drive group. The normal `wsprrypi.service` must remain stopped and disabled.

This is a software implementation and RF-free verification task. Device access, installation, deployment, service changes, ZERO/CAL, and live RF require a separate instruction. Do not commit, push, or publish.
